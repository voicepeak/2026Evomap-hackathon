## 1. 一页摘要

**一句话定位**

> 卖一套"**安全采集套件 + 绝对编码遥操输入 + 边缘采集盒**"，让非专家也能在平台上产出**标准化、可溯源、可训练**的机器人演示数据，并把数据卖给 / 服务于具身智能团队。

**三层产品**

| 层 | 内容 |
|---|---|
| 硬件 | 遥操输入设备（HID）+ 机械臂安全适配套件 + Edge 采集盒 + 相机套件 |
| 软件 | 采集 App（录 / 停 / 重录 / 质检）→ 平台（配置 / 标定 / 数据集 / 授权）→ 买家端（预览 / 验证 / 下载） |
| 数据 | LeRobot 标准 schema + 扩展（标定 / 同步 / 质量 / 授权 / 签名） |

**三阶段商业路径**

1. 卖工具与服务（现金流）
2. 卖代采服务与订阅（验证单价）
3. 数据市场与抽成（平台化）

**12 个月目标**

- 100 台设备在线
- 交付 5 万条合格 episode
- 3 家付费数据买家
- 单条数据综合成本 < ¥50
- ACT 抓取成功率 ≥ 60%

**三个赌注（也是护城河）**

1. **安全认证体系**（抱闸 + 平衡 + UPS + 急停 + 状态机）
2. **出厂标定 / 一键配置**（消灭 ID、方向、零点、限位的人工配置）
3. **力反馈输入设备**（接触 / 力控数据的唯一低成本来源）

我们不是从零开始。以下资产已可直接复用：

| 类型 | 已有 | 直接变成 |
|---|---|---|

## 4. 产品架构

```
┌─ 输入层 ─────────────┐   ┌─ 采集层 ────────────────┐   ┌─ 平台层 ──────────────┐
│ 6-DoF 绝对编码手柄    │   │ Edge 采集盒(Jetson+NVMe) │   │ 配置服务(标定/方向/限位) │
│ 数位板(兼容)          │──▶│ 采集App(录/停/重录/QC)   │──▶│ 数据集仓库(LeRobot v3+) │
│ 手势/脚踏(辅助)       │   │ 相机套件(触发同步)       │   │ 质量评分/去重/签名      │
└──────────────────────┘   └─────────────────────────┘   │ 授权与交易 / 买家端预览 │
        ▲                                                   └────────────────────────┘
        │ 安全适配套件：抱闸 + 重力平衡 + UPS + 急停 + 自检固件
        └── 机械臂（B601-RS/DM、SO-101、OpenArm 适配板）
```

### 4.1 输入设备 HID（v1 规格）

| 项 | 指标 |
|---|---|
| 自由度 | 6-DoF（3 平移 + 3 旋转），绝对磁编码（AS5047P / MT6835 21bit） |
| 分辨率 / 精度 | ≤ 0.05 mm / ≤ 0.05° |
| 采样与延迟 | 本地 1 kHz 控制环，端到端 < 3 ms |
| 接口 | USB-C（CDC + HID 兼容），可选以太网 |
| 控制件 | 扳机（夹爪）、2 侧键（平面 / 模式）、死开关（握持或脚踏）、录制键 |
| 时钟 | 硬件时间戳（µs）+ 相机触发输出 |
| 安全 | 看门狗、断连即停、限速 / 限幅在 MCU 侧完成 |
| v2 选配 | 3-DoF 力反馈（BLDC + 钢丝绳），采集接触 / 力控数据 |
| BOM 目标 | 基础版 < $150，力反馈版 < $400 |

### 4.2 机械臂安全适配套件

对应实测事故（失能掉落、漂浮启动下坠）：

- J2 / J3 **气弹簧 / 扭簧** 抵消 40% 重力矩（降掉速、降发热）
- J2 / J3 **失电抱闸**（保持力矩 ≥ 1.5× 静态重力矩）
- **48V UPS**（≥ 3 s，够 park + 抱闸）
- **双回路急停**（底座 + 手持）
- **涡流 / 摩擦阻尼** 限制下坠角速度
- 固件：上电自检（扫描 7 电机、`clear_error`、读故障码）、温度 / 电压 / 电流监控、碰撞检测（重力模型残差 < 50 ms 停止）、模式切换预加载力矩
- 适配套件目标：可装 B601-RS / DM、SO-101、OpenArm（三种底板 + 转接件）

### 4.3 Edge 采集盒

- Jetson Orin Nano + NVMe
- 免驱 USB-CAN（gs_usb / candleLight）
- 双相机（wrist + 固定）
- 预装 Ubuntu RT + Docker 镜像
- 一键开机、本地质检、断网续传

> **它同时是平台锁定入口与支持成本杀手。**

### 4.4 软件栈

| 端 | 功能 |
|---|---|
| 采集 App | 遥操 / 录制 / 丢弃 / 重录、任务提示、质量灯（速度 / 抖动 / 限位实时提示）、一键上传 |
| 平台 | 设备管理、标定与配置下发、数据集管理、质量评分、去重、签名、任务派单 |
| 买家端 | 预览（视频 + 轨迹 + 统计）、验证集抽样、授权范围选择、下载 / API |
| SDK | Python（对齐 LeRobot）、CLI、HTTP API；发布数据集到 HF 作为可信通道 |

### 4.5 数据标准 v1（在 LeRobot dataset v3 上扩展）

| 类别 | 字段 |
|---|---|
| 轨迹 | 7×关节 pos / vel / torque（统一 rad、rad·s⁻¹、N·m）、夹爪 pos / force、action 序列 |
| 相机 | wrist + 2 路固定（640×480 @ 30 fps，MP4 / H.264），**每帧硬件时间戳** |
| 硬件 | 臂型号 / 序列号、电机型号表（RS06×3 / RS00×4）、方向符号表、限位、控制模式、kp / kd、固件版本、CAN 速率 |
| 标定 | URDF 版本、零点偏置、相机内外参、标定哈希 |
| 任务 | 语言指令、场景 / 物体标签、成功 / 失败、episode 边界、操作者匿名 ID |
| 质量 | 平滑度、限位占用、丢帧率、温度峰值、重力残差、成功率 |
| 授权 / 溯源 | 授权范围（训练 / 商用 / 转售）、期限、脱敏标记、**Ed25519 签名** |

## 5. 关键技术方案

### 5.1 一键配置生成（把"参数 / 方向"这件事彻底消灭）

1. 每个电机模块 / 相机架带身份芯片（EEPROM / NFC），存序列号与出厂标定
2. 设备开机 → 平台读身份 → **自动生成**：
   - 电机 ID 1–7
   - 型号（J1–3 RS06；J4–6 + 夹爪 RS00）
   - 方向符号、零点、软限位
   - MIT kp / kd（默认 50/3、150/10、150/10、50/5、50/4、50/4）
   - `limit_torque` 36 / 14
   - `loc_kp` / `spd_kp` / `acc_rad` / `vel_max`
3. 用户界面只有两件事：**扫码 → 点"开始"**

### 5.2 安全状态机（固件级，不依赖上位机）

```
IDLE → SELF_TEST → CALIBRATE → HOLD(park) → OPERATE → PARK → DISABLE
```

- 只有 `HOLD(park)` 才允许 `DISABLE`；`OPERATE` 中失能请求 → 先 PARK
- 掉电 / 断连 / 看门狗 → 抱闸 + 限速停止
- 任何模式切换：**先给 tau，再放 kp**（消灭 0.5 s 空窗下坠）

### 5.3 同步采集与质量门

- 相机硬件触发 / 统一时钟；关节状态与帧共用时间基准
- 自动质检规则：
  - 丢帧 < 2%
  - 限位占用 < 5%
  - jerk 超限告警
  - 遮挡 / 光照检测
  - **episode 必须"成功收尾"**
  - 轨迹去重（哈希 + 特征）
- 不合格数据在采集端就标红，**不让脏数据进平台**

### 5.4 溯源、合规与隐私

- 安全芯片（ATECC608A / SE050）签名 manifest → 证明"来自标定过的设备、未篡改"
- 物理隐私：镜头硬件开关 + 录制指示灯 + 本地模糊
- 授权链：采集者在 App 内选择授权范围；数据 / 合同 / 期限三件套

### 5.5 跨平台支持（把 macOS 那几小时变成 0）

- 默认 **gs_usb / candleLight 免驱 USB-CAN**
- 一键安装脚本（Linux / macOS / Windows）
- Ubuntu RT 镜像 + Docker
- 固件 OTA（A/B 分区 + 签名）

- 不碰医疗 / 工业级认证（CE / FCC + 软件安全足够）
- 不做通用云平台（先本地 Edge + 轻平台）

## 附录 B：已知坑与产品级对策

> 全部来自 B601-RS 实测会话（macOS + 真实硬件）

| # | 坑 | 现象 | 产品级对策 |
|---|---|---|---|
| 1 | 电机故障锁存 | J3 电流恒为 0、无故障码，指令无响应 | 上电自检自动 `clear_error` + 故障码上报 + LED 指示 |
| 2 | 零位 = 下限 | J2 / J3 反向顶限位，20A 电流不动作 | 配置生成器内置限位；越限前告警 |
| 3 | 失能掉落 | 归零被打断后失能，J2 掉 8.8° | 仅 park 位允许失能；抱闸硬件兜底 |
| 4 | 切模式空窗下坠 | `disable_all()` 0.5 s 无力矩，末端掉 45 cm | 先给 tau 再放 kp；UPS + 抱闸 |
| 5 | 关节方向 / 标定 | 实际转向与模型不符，IK 结果偏 12 cm | 出厂标定 + 身份芯片自动生成方向符号 |
| 6 | macOS 驱动 | PCBUSB 路径、uv 剥离 `DYLD_*`、PCAN 掉线 | 默认 gs_usb 免驱适配器 + Edge 盒（Ubuntu RT） |
| 7 | 环境割裂 | ROS2 / Isaac Sim / LeRobot 默认全在 Ubuntu | 提供 Ubuntu RT 镜像 + Docker + 一键脚本 |
| 8 | 手势不稳 | 掌心丢失、上下识别抖动 | 手势只做辅助；主通道用绝对编码设备 |
