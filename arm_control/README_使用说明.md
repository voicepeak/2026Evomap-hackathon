# reBot Arm B601-RS · 数位板遥操作系统（最终版）

一支数位板笔 + 键盘/屏幕按钮，控制 6 关节机械臂 + 夹爪，全程悬停不下坠。

---

## 一、交付内容

| 类别 | 文件 | 作用 |
|---|---|---|
| **主控制台** | `spatial_teleop.py` | 空间运动 + 工具姿态 + 关节直控 + 夹爪 + 悬停，全部功能 |
| **精密关节台** | `joint_teleop.py` | 单关节 0.01° 级定位（摆姿态、标定用） |
| **安全失能** | `disable_arm.py` | 先归零后失能（唯一推荐断电方式） |
| **桌面启动器** | `~/Desktop/启动机械臂.command` | 双击启动主控制台（自动检查实例/零位） |
| 工具 | `tools/pos_check.py` | 只读检查：当前关节角、是否可安全启动 |
| 工具 | `tools/go_zero.py` | 任意姿态缓慢归零 |
| 工具 | `tools/return_home.py` | 带力矩/跟随监测的温和归零（卡住会停） |
| 工具 | `tools/joint_demo.py` | 逐电机小角度演示（识别每个电机作用） |
| 工具 | `tools/grip_calib.py` | 夹爪行程标定 / 手动驱动（带力矩保护） |
| 工具 | `tools/grip_zero.py` | 夹爪零点重设（0° = 爪片合到位）+ 行程复测，只动夹爪 |
| 工具 | `tools/grip_check.py` | 夹爪状态诊断（位置/故障码/软响应） |
| 配置 | `config/rebotarm_rs.yaml` | 电机、CAN、MIT kp/kd 参数 |
| 数据 | `config/poses.json` | 姿势预设（教学记录，可跨次使用） |

已停用但保留（不再使用）：`hybrid_teleop.py`、`cam_server.py`、`cam_view.py`、`cam_probe.py`、`phone_ctrl.py`、`tools_pen_teleop.py`。

## 二、主控制台操作

### 笔（唯一的运动输入，松开即停）
| 模式 | 笔上下 | 笔左右 | Shift+上下 |
|---|---|---|---|
| **位置模式**（默认） | 末端前伸 / 后收 | 左移 / 右移 | 升 / 降 |
| **姿态模式**（按 `O` 切换） | 工具俯仰 | 工具摆头 | 工具侧倾 |

### 键盘
| 键 | 作用 |
|---|---|
| `Q` / `A`（按住） | 直控选中电机的 **正转 / 反转** |
| `[` `]` | 切换直控选中的电机 |
| `,` `.`（按住） | J6 夹爪自转 |
| `H` | **悬停模式**开/关（可用手推动机械臂，松手停在原地） |
| `O` | 位置模式 ↔ 姿态模式 |
| `F` | 速度档：慢 / 中 / 快（4 / 8 / 16 cm/s） |
| `Space` | 冻结 / 解冻（笔侧键同） |
| `R` | 重新对齐（当前姿态设为参考） |
| `1`~`4` / `Shift+1`~`4` | 前往 / 记录 姿势预设 |
| `Esc`（按两下） | 退出（先平滑归零，不失能） |

### 屏幕按钮（用笔点）
`位置模式` `姿态模式` `悬停模式` `冻结/解冻` `速度档` + `J1`~`J6` `夹爪`（选择直控电机）

## 三、机械参数（已实测标定）

### 关节
| 电机 | 作用 | 范围（URDF） | 备注 |
|---|---|---|---|
| J1 | 底座旋转 | ±160.4° | |
| J2 | 肩（大臂俯仰） | 0 ~ +179.9° | 零位=下限 |
| J3 | 肘（小臂俯仰） | 0 ~ +179.9° | 实测可到 203°（URDF 偏保守） |
| **J4** | **手腕俯仰** | ±90° | |
| J5 | 手腕水平摆 | ±90° | |
| J6 | 夹爪自转（末端不移动） | ±179.9° | |
| 夹爪 | 开合（自锁型，不通电掰不动） | 机械端 **−11.9° / +335.4°** | 程序可用 **+3° ~ +328°** |

### 控制
- 空间速度：4 / 8 / 16 cm/s（三档）
- 关节直控速度：60 °/s（指令值，实际受零空间/限位影响）
- 关节软限位余量、笛卡尔安全盒：均可在命令行调整或关闭
- 夹爪速度：69 °/s，力矩保护 1 N·m（超限自动停 + 目标回退）

## 四、安全机制

- **全程重力补偿悬停**，任何情况下不断力矩、不失能（断电只走 `disable_arm.py`）
- **松笔即停**：速度级控制，不存在目标累积乱走
- **冻结**：`Space` / 笔侧键 → 立即刚性保持
- **退出**：`Esc` 两下 → 最小 jerk 平滑归零再退出
- **异常/崩溃**：先尝试温和归零（力矩监测）再退出，不中途松手
- **启动保护**：机械臂不接近折叠零位时拒绝使能（不失能、不硬来）
- **力矩保护**：超阈值自动冻结（默认关闭/可配）
- **夹爪专项**：软刚度（kp=20）+ 限速 + 力矩保护 + 目标回退
- ⚠️ 安全盒关闭时（`--no-box`）没有碰撞保护，需自行注意

## 五、日常流程

```bash
# 启动（或双击桌面 启动机械臂.command）
cd "/Users/Admin/Desktop/reBotArm_control_py"
~/.local/bin/uv run python spatial_teleop.py

# 开放全部限位（无安全盒 + 0 余量）
~/.local/bin/uv run python spatial_teleop.py --no-box --limit-margin 0 --tau-limit 20

# 只看姿态（只读，不动电机）
~/.local/bin/uv run python tools/pos_check.py

# 缓慢/温和归零
~/.local/bin/uv run python tools/go_zero.py
~/.local/bin/uv run python tools/return_home.py

# 安全断电
~/.local/bin/uv run python disable_arm.py
```

## 六、已知限制

1. 夹爪传动比大：全行程≈电机转 325°，视觉上爪片移动幅度小（属正常）；面板"已探到"实时显示实际走过范围
2. 关节 URDF 限位比真实机械限位保守（J3 实测可到 203°）
3. 无碰撞检测、无力矩反馈闭环以外的保护
4. 数位板窗口需保持焦点（键盘事件只在该窗口内生效）
5. 姿态是"软保持"：不主动锁姿态时，工具姿态会随空间运动自然变化
6. 关闭控制进程后电机由通信看门狗释放，机械臂停在折叠零位（重力自稳位，安全）
